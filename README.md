One line, at most 100 characters, that sums up the entrant's week: the win, the fail, the chaos.

The entry line (85 characters):

> 196 entries, zero wins, nine cents: my week was a slot machine that pays in exposure.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`.
